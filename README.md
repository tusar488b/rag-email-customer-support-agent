RAG Email Customer Support Agent

An AI-assisted email customer support workflow built with n8n, Google Gemini, Supabase, and Gmail.

Project Overview

This project explores how Retrieval-Augmented Generation (RAG) can help an AI assistant retrieve relevant information from a knowledge base and draft helpful customer support email replies.

The workflow is currently under development and testing.

Planned Features

- Retrieve relevant information from a knowledge base
- Use AI to draft context-aware email responses
- Automate parts of the customer support process
- Integrate workflow steps using n8n
- Explore vector search with Supabase
- Prepare email responses through Gmail integration

Technologies

- n8n — Workflow automation
- Google Gemini — AI model and embeddings
- Supabase — Vector database and retrieval
- Gmail — Email integration
